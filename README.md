# Counterspell NFC 📱✨



**Counterspell NFC** is a cutting-edge mobile app, part of **Counterspell Silicon Valley's NFC System**, designed to revolutionize how organizers manage attendees and rewards. With powerful features for scanning and writing NFC cards, this app streamlines event experiences like never before.



---



## 🌟 Features



### 🎫 **NFC Card Management**

- **Write NFC**: Easily write attendee data to their NFC cards in seconds.

- **Event Attendance**: Seamlessly track event check-ins with just a tap.



### 💰 **Reward System**

- **Grant XP**: Reward attendees with XP, our unique event currency, to keep engagement high.

- **Buy Prize**: Allow attendees to redeem XP for exciting prizes with a simple scan.



### 🕵️‍♀️ **Interactive Scavenger Hunts**

- **Create Hunt**: Design and manage NFC-based scavenger hunts to add an extra layer of fun to your events.



### 🔍 **Data Insights**

- **Get Data**: Access detailed data about attendees, attendance, and rewards right from the app.



---



## 📱 Built With

- **Framework**: [Expo](https://expo.dev/) for React Native, ensuring smooth cross-platform compatibility.

- **UI/UX**: A sleek and intuitive interface for effortless event management.



---



## 🚀 How It Works

1. **Scan**: Use the app to scan NFC cards given to attendees.

2. **Write**: Input and store attendee data or assign XP directly onto the card.

3. **Engage**: Create scavenger hunts, reward XP, or track attendance with ease.

4. **Redeem**: Let attendees exchange XP for prizes right on the spot!
